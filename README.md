# KreativWerkstatt – CI & Claude-Notizen

Privates Repo mit der Corporate Identity der KreativWerkstatt als Claude-Skill.

- `.claude/skills/kreativwerkstatt-ci/` – CI-Skill: Logo, Hausfarben, Schrift, Gestaltungsregeln
- `CLAUDE.md` – Arbeitsvorlieben, die Claude in jeder Session mit diesem Repo befolgt

Startet eine Claude-Cloud-Session mit diesem Repo, lädt Claude den Skill automatisch.
